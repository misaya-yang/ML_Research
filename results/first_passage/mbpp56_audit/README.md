# MBPP56：首次验证读出前的祖先证书

这是 **历史回执复算**，不是重新推理或独立验证所有浮点证书。原策略是同一台设备上固定顺序、最多四个不同程序的首次公开验证读出（K4），不是 Power-SMC 原生的单一加权输出。56/56 条记录的验证路径匹配；Full 和 Across 均为 35 正确、6 错误、15 无交付。串行总时间 391.333 → 323.276 秒；不能据此宣称并发吞吐或原生单样本质量。

32 题保存了全部祖先映射，记录可将 **14,058 个解码位置和 556 次调用** 的省略与终端读出分开（分别是 Full 解码位置的 11.49%、解码调用的 11.45%）。第 468 题的 64 个单槽证书另支持 305 个位置、9 次调用；这题本身墙钟反而变慢。能迁移的是证书覆盖下的工作量解释，不是已经观察到的速度或正确率。移植到加权读出时，即使父槽唯一，也不能在未证实重采样时将继承权重置零。

**从仓库根目录复算，只需 Python 3 标准库：**

```sh
p=results/first_passage/mbpp56_audit
run_dir=$(mktemp -d)
python3 "$p/audit_reader_independent_certificates.py" \
  --compare-audit "$p/reference.json" --output "$run_dir/recomputed.json"
```

`raw/` 是一份冻结计数回执；`code/` 是供 SHA-256 核验的六份原始源文件，不是独立可运行的模型包。`reference.json` 只保存审计能复核的总量和逐题字段。不重跑任何生成程序。更广的研究结论见[证据索引](../../../RESEARCH_INDEX.md)。
