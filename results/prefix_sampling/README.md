| Study | Result | Boundary |
| --- | --- | --- |
| Thought Anchors restart headroom | For failed base traces with positive fresh baseline, median midpoint efficiency 0.75× (R1-Distill-Qwen-14B) and 0.54× (R1-Distill-Llama-8B). In the matched-budget proxy replay, held-out quarter and midpoint were also below fresh. | One base trace per outcome per problem, 20 problems/model, remaining characters as cost proxy. [Receipts](archive/thought_anchors.log), [budget replay](archive/budget_replay.log). |
| Prefix Consistency archival cutoff/retry | Leave-one-problem-out fixed cutoff tied plain IID at all 5 budgets in all 7 observed model×task cells. Reusing the late 75% prefix repeated the prior wrong answer at 24–62%, vs 2–11% from fresh samples in the matched cells. | Integer-answer scoring, 23–30 questions/cell for cutoff replay. Checked-failure and empirical archive resampling, not a new model run or a lower bound on other methods. [Cutoff](archive/cutoff_replay.log), [inheritance](archive/inheritance.log). |
| Capped fork + fresh fallback | On archived Ministral‑14B BRUMO, frozen AIME rule: 22.792% routed vs 17.659% full fresh (16 integer-answer problems; +5.133 pp; descriptive question bootstrap 0.692 to 10.681 pp). On HMMT: 6.855% vs 5.602% (17 problems; interval includes zero). In separate live M4 Qwen2.5 transfer, route and full fresh rescued the same 1/12 failures; route used 2,969 vs 3,069 generated tokens but took 271.834 vs 262.419 seconds. | Same-model archive transfer is not live validation; the live small-model result is an accuracy tie, not a physical speedup. [Archive transfer](transfer/ministral_strong_cross_task.log), [compact live replay](transfer/live_compact.jsonl). |
| Original Claude Gate 1 | Three CRT calibration candidates all missed the short-length screen. [Receipt](calibration/receipt.json) with original hashes and [frozen screen](calibration/protocol_v2.json). Separate from E1-P. |
| Claude E1-P main experiment | F1: 2,048/2,048 hit the 24-token cap, none produced a boxed answer. F2 IID was in progress at this checkpoint; no completed main lattice result or F3 included. [Receipts](e1p/). |

[Scores](e1p/countdown_control_report.json), [diagnostic](e1p/countdown_predictor_diagnostic.json). |
