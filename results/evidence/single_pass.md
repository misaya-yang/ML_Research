# 冻结模型，零训练采样

这条线和固定策略的首达加速分开。目标是少量、最好一次生成，在固定提示、无验证器和固定 token 上限下提高最终正确率；理论构造只回答可能性。

## 低样本投票：机制没有兑现

三票、同样预算的构造中，每条分支答对率均为 40%，答错时给出该分支特有的错误答案。固定各抽一条的正确率为 49.6%，而最好的同混合分布独立抽样为 44.8%。结果来自避免重复的错票；不需要在中途知道哪条推理正确。这不是对真实模型或一切独立非同分布设计的保证。另一个大样本构造有常数差距，但不作为实用方案。

[精确分数核验](../../experiments/check_three_vote_sampling.py)也复算了三票上限：若固定正确票数和有效票数，仅能更改错票身份，那么只有“一张正确票、两张相同错票”的情况可救，且拆开后的最大收益是 1/3（变成三方平票）。

Qwen3-1.7B Q4_K_M 实跑：24 道 GSM8K，每方法三次生成，不训练、不验证。T=.75 独立抽样 72.2%，同边际的跨样本耦合 76.4%；两题差异分别来自多抽到正确答案和少一次无有效答案，不是分散错票。384 token 硬上限的重放中，和最强独立对照均为 54.17%，它没有可通过拆开重复错票救回的实例。这里没有证明真实任务中不存在该类错误，也不应扩大这批题去追击它。

## 单次生成：高概率候选与长尾需分开评估

匹配尾部概率和高概率候选总质量，只改变高概率候选之间的相对权重。现行实验保持各候选原有比例，不尝试用中途信息判对错。在固定组概率下，保留比例使高概率组内最坏的相对保留率最大；不保证每条正确推理都在组内，也不保证比原分布更准。

500 道 MATH500 的 [公开开头 token 条件轨迹](https://huggingface.co/datasets/ChrisMcCormick/math-rollouts)中，Qwen2.5-Math-1.5B 仅在开头对核内概率平方，正确率约下降 1.25 个百分点；保持组内比例挽回 1.10 个百分点（配对区间 [0.68, 1.52]），仍未超过保持原分布。此结果仅限第一个 token 的归档重算，不等于整条生成或其它模型。对 Oat-Zero 的影响接近零。

## 单次生成实跑：没有赢过简单的 Min-p

Qwen3-1.7B Q4_K_M，固定提示、同一数值答案解析器、每臂每题只生成一条，256 token 硬上限。64 道未用于上一轮的 GSM8K，16 道开发题只用于选择固定温度对照，另 48 道留出题。各臂在实验间共用随机数配对；实际使用任何一个采样器都只需一次生成。EM-INF 对照实现论文式 (5)，不是作者任务专用代码或重调的最强配置。

| 采样 | 留出正确数 / 48 | 平均生成 token |
| --- | ---: | ---: |
| Greedy | 25 | 152.40 |
| T=1.0 | 30 | 154.42 |
| T=0.75 | 29 | 151.29 |
| T=0.5（开发集所选） | 29 | 153.98 |
| EM-INF 式 (5) | 27 | 153.04 |
| 自适应温度 | 28 | 153.13 |
| 保留组内比例 | 29 | 152.44 |
| 保留一半组内调整 | 29 | 151.38 |
| Min-p | **31** | **148.10** |

完整保留组内比例相对其对应的自适应温度有 2 胜 1 负，净 +2.08 个百分点（配对 bootstrap 区间 −4.17 至 +10.42）。但相对开发集选出的 T=0.5 正确数持平；相对 Min-p 少对 2 题、平均多生成约 4.33 token。这两种候选都不继续当作提质方案。T=1 正确的 30 条中有 12 条至少用过一次长尾 token，说明“正确轨迹完全留在头部”的理论保护条件在此并不普遍。等上限不等于等实际 token 或墙钟。单个量化模型和一组算术题也不足以否定整个零训练单次采样方向。
